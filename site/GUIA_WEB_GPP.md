# Portal web de inteligencia comercial

Abrir `index.html` para consultar la introducción y `dashboard.html` para explorar las ocho vistas interactivas: panorama, rentabilidad, portafolio, inventario, calidad, pronóstico, simulador y metodología.

El sitio utiliza `styles.css`, `app.js` y `data.js`, con rutas relativas compatibles con alojamiento estático. Los indicadores provienen de transformaciones documentadas en `src/` y `docs/` y no requieren una API externa para mostrarse.

La simulación representa sensibilidades aritméticas, no inferencias causales ni estimaciones de elasticidad.

**Procedencia:** Jimmy Smith, *Retail Transactions and Stocks Data*, Mendeley Data v1. DOI: https://doi.org/10.17632/27x8mjm8k4.1. Licencia CC BY 4.0. Los datos no pertenecen a GPP Group.
